# FCC Prime Checker
Method for checking the primeness of numbers.

## Installation
Clone the repository
```bash
git clone https://github.com/MeBenji/fcc-prime-checker.git
```

## Usage
```javascript
const { isPrime } = require("./index");

console.log(isPrime(3)); // true
console.log(isPrime(4)); // false
```
